# Ray

AI engineer focused on practical tools and reliable software.

I value clear scope, reproducible behavior, and honest documentation.

## Selected work

- [conversational-intent-compiler](https://github.com/ray-works-jp/conversational-intent-compiler) — A plugin and CLI that keeps a conversation's original text as the source of truth and tracks what changed, what is still open, what was delegated, and what is not authorized. Works with Claude Code, Antigravity and ChatGPT/Codex. Python, tested, MIT.
- [relayguard](https://github.com/ray-works-jp/relayguard) — A local reviewer that stops over-promising in English e-mail replies: anything a human did not approve (amounts, dates, refunds, links) halts the check. Deterministic Python checks, no e-mail sending, 2,793 tests. Source-available (noncommercial use only).

Both projects state what they do not verify, and say so in the README.
